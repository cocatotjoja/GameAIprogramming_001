### Using the program

To shift between different states for the Ai agents the user can press the numbers on the keyboard;
1. Seek
2. Flee
3. Pursue
4. Evade
5. Arrive
6. Wander
7. Path Following


User can control a player which is used as target for;
* Seek
* Flee
* Pursue
* Evade
* Arrive
The player is controlled using the arrows on the keyboard.
